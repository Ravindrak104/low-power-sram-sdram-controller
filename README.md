# Low-Power Optimized 64-Bit SRAM and SDRAM Controller

## Overview

This project focuses on the design and implementation of low-power optimized 64-bit SRAM and SDRAM controllers for energy-efficient VLSI applications.

The controllers are designed using Verilog HDL and verified through RTL simulation using Xilinx Vivado. Low-power optimization techniques, including clock gating and power gating, are incorporated to reduce unnecessary switching activity and power consumption during idle conditions.

The design flow also includes logic synthesis using Cadence Genus and physical design using Cadence Innovus to explore the implementation of optimized memory controllers.

## Key Features

- 64-bit SRAM and SDRAM controller design
- RTL design using Verilog HDL
- Read and write operation verification
- Clock gating for reduced switching activity
- Power gating for reduced leakage during idle periods
- Functional simulation and RTL schematic analysis
- Logic synthesis using Cadence Genus
- Physical design using Cadence Innovus
- Power analysis and implementation evaluation

## Tools and Technologies

- Verilog HDL
- Xilinx Vivado
- Cadence Genus
- Cadence Innovus
- RTL Simulation
- VLSI Synthesis and Physical Design

## Project Objective

To investigate low-power memory controller architectures that maintain functional correctness while reducing unnecessary power consumption in digital VLSI systems.
